## ✨ Sobre o Projeto

Este projeto é um **Santinho Eleitoral Virtual**, desenvolvido para a matéria de **Atividade Prática Supervisionada (APS)**. O objetivo foi criar uma aplicação web interativa que simula o processo de votação em um "santinho" para as eleições municipais.

O projeto foi criado seguindo uma abordagem de **"documentação em cascata"**, onde cada etapa do desenvolvimento foi registrada e estruturada, demonstrando um processo de trabalho organizado e profissional. É uma ótima maneira de exibir habilidades de programação e documentação de projetos.

🔹 Principais destaques:

* ✅ Simulação interativa de um processo eleitoral
* ✅ Design visual claro e responsivo para uma experiência intuitiva
* ✅ Aplicação de conceitos de **HTML, CSS e JavaScript** para criar a interface e a lógica
* ✅ Projeto acadêmico com foco em boas práticas de desenvolvimento e documentação
